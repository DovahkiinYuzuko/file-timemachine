# ファイルタイムマシン AAUI イメージ (v3: フォルダ選択追加)

ユズコとの再検討で固まった、フォルダ選択機能と視認性を改善した最強UIイメージだよ！

## 1. メイン画面レイアウト
左端のバーに `FolderOpen` (📁) を追加。アイコンはすべて Lucide (SVG) に統一。

```text
+---+----------+------------------+---------------------------+
|   | (Folder) | 🕒 履歴・ルート  |      [ プレビュー ]       |
|📁 | 📂src    | +--------------+ |                           |
|---|  memo.txt| | [メイン]     | | ファイル: memo.txt        |
|📄 |  conf.js | |  ○---● (今)  | | ------------------------- |
|🕒 |          | +--------------+ | (ここに中身が表示)        |
|---| 📂tmp    | | 14:00 (保存) | |                           |
|⚙️ | (ign)    | | 13:30 (保存) | |      [可変幅 / Scroll]    |
|❓ |          | | 12:00 (保存) | |                           |
+---+----------+------------------+---------------------------+
| [● 今の状態を保存する]                                      |
+-------------------------------------------------------------+
```
※ 左端バーのアイコン: `FolderOpen` (📁), `Files` (📄), `History` (🕒), `Settings` (⚙️), `HelpCircle` (❓)

## 2. 設定画面 (Modal - 視認性改善版)
背景を不透明の濃色にし、背後をブラーでぼかす「最強視認性」仕様。

```text
+-------------------------------------------------------------+
|  [ ⚙️ 設定 ]                                            [X] |
+-------------------------------------------------------------+
|  [ ユーザー連携 ]                                           |
|    GitHub: [ 未連携 ]  -> [ 🔗 ブラウザで連携 (OAuth) ]     |
|                                                             |
|  [ 言語設定 ]                                               |
|    言語: [ 日本語 🇯🇵 ▼ ] (全世界主要言語に対応)            |
|                                                             |
|  [ アプリ挙動 ]                                             |
|    ルート切り替え時の保存: [ 確認する / 全自動 / しない ]   |
|                                                             |
|  [ その他 ]                                                 |
|    脆弱性スキャンを自動で実行する: [ ON / OFF ]             |
+-------------------------------------------------------------+
```

## 3. 既存Gitフォルダの扱い
すでに `.git` がある場合でも、既存の歴史を尊重して読み込む。

```text
+---------------------------------------------------------+
|                  ℹ️ 既存リポジトリ                     |
|                                                         |
|  このフォルダは既にGitで管理されています。              |
|  既存の履歴を読み込みました！                           |
|  ( .gitignore がない場合は作成を提案します )            |
|                                                         |
|  [ OK ]                                                 |
+---------------------------------------------------------+
```
