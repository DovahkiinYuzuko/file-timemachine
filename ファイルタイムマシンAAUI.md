# ファイルタイムマシン AAUI イメージ

ユズコとのブレインストーミングで固まったUIのイメージ図だよ！

## 1. 通常モード（4カラム：ファイルツリー + 履歴リスト）
各ペインの幅は可変（Resizable）で、中身が溢れたらスクロールバーが出る親切設計！

```text
+------+----------+------------+---------------------------+
| 📁   | ルート▼ | 履歴リスト |      [ プレビュー ]       |
| 📂src| [メイン] | 14:00 (今) |                           |
|  memo|  案B     | 13:30      |  (ここに中身が出る！)     |
|  conf|  案C     | 12:00      |                           |
| 📂tmp|          |            |      [可変幅 / Scroll]    |
| (ign)| [グラフ] |            |                           |
+------+----------+------------+---------------------------+
| [● 今の状態を保存] | [お試しルート] [本番に採用]         |
+--------------------+-------------------------------------+
```

## 2. グラフモード（切り替え後）
中間のペインをドーンと広げて、SVGで描画されたGitグラフを俯瞰するモード。

```text
+------+----------+----------------------------------------+
| 📁   | ルート▼ |            [ グラフビュー ]            |
| 📂src| [リスト] |      ○ [案C]                           |
|  memo| [へ戻す] |     /                                  |
|  conf|          |  ●---○---○ [メイン]                     |
| 📂tmp|          |   ＼                                   |
| (ign)|          |     ○---● (今) [案B]                   |
+------+----------+----------------------------------------+
| [● 今の状態を保存] | [お試しルート] [本番に採用]         |
+--------------------+-------------------------------------+
```

## 3. セットアップウィザード（初回起動時）
依存ツール（Git, Homebrew, gh）がない場合の案内画面。

```text
+---------------------------------------------------------+
|                [ おまかせセットアップ ]                 |
|                                                         |
|  あーしが準備を手伝うよ！今の状況はこんな感じ：         |
|                                                         |
|  1. Git: [ 未インストール ] -> [ インストールする ]     |
|  2. Homebrew: [ 未検出 ]    -> [ ガイドを表示 ]         |
|  3. GitHub CLI: [ OK ]                                  |
|                                                         |
|  [ 次へ ]                                               |
+---------------------------------------------------------+
```

## 4. 安全ガード（警告ダイアログ）
デカいファイルや秘密のファイルを保存しようとした時のストッパー。

```text
+---------------------------------------------------------+
|                  ⚠️ ちょっと待って！                   |
|                                                         |
|  以下のファイルは保存しないほうがいいかも：             |
|  - .env (秘密の情報が含まれてるよ！)                    |
|  - movie.mp4 (サイズがデカすぎるよ！ 1.2GB)             |
|                                                         |
|  [ 除外して保存 ]  [ 構わず保存する ]  [ キャンセル ]   |
+---------------------------------------------------------+
```
