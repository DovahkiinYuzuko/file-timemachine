# ファイルタイムマシン AAUI イメージ (v2: ハイブリッド)

ユズコとの再検討で固まった、サイドバー付きの最強ハイブリッドUIイメージだよ！

## 1. メイン画面レイアウト
左端にスリムなアクティビティ・バー、右側に3つの可変幅パネルを配置。

```text
+---+----------+------------------+---------------------------+
|   | 📁       | 🕒 履歴・ルート  |      [ プレビュー ]       |
| 📁| 📂src    | +--------------+ |                           |
|   |  memo.txt| | [メイン]     | | ファイル: memo.txt        |
| 🕒|  conf.js | |  ○---● (今)  | | ------------------------- |
|   |          | +--------------+ | (ここに中身が表示)        |
|---| 📂tmp    | | 14:00 (保存) | |                           |
| ⚙️| (ign)    | | 13:30 (保存) | |      [可変幅 / Scroll]    |
| ❓|          | | 12:00 (保存) | |                           |
+---+----------+------------------+---------------------------+
| [● 今の状態を保存する]                                      |
+-------------------------------------------------------------+
```
※ アイコン（📁, 🕒, ⚙️, ❓）は Lucide-react の SVG アイコンを使用。

## 2. 設定画面 (Modal)
```text
+-------------------------------------------------------------+
|  [ ⚙️ 設定 ]                                            [X] |
+-------------------------------------------------------------+
|  [ ユーザー連携 ]                                           |
|    GitHub: [ 未連携 ]  -> [ 🔗 ブラウザで連携 (OAuth) ]     |
|                                                             |
|  [ 言語設定 ]                                               |
|    言語: [ 日本語 🇯🇵 ▼ ] (世界各国の主要言語を選択可能)     |
|                                                             |
|  [ アプリ挙動 ]                                             |
|    ルート切り替え時の保存: [ 確認する / 全自動 / しない ]   |
|                                                             |
|  [ その他 ]                                                 |
|    脆弱性スキャンを自動で実行する: [ ON / OFF ]             |
+-------------------------------------------------------------+
```

## 3. ヘルプ ＆ Gitコマンド早見表 (Modal)
```text
+-------------------------------------------------------------+
|  [ ❓ ヘルプ ＆ Git早見表 ]                             [X] |
+-------------------------------------------------------------+
|  このアプリの操作     Gitコマンド      解説                 |
|  ------------------  --------------  ---------------------  |
|  ● 保存する          git commit      今の状態を記録するよ   |
|  🌱 お試しルート    git branch      別の道を作るよ         |
|  🔄 切り替える      git checkout    過去や別の道へGO！     |
|  ✅ 本番に採用      git merge       良い案を合体させるよ   |
|  🔍 中身で探す      git grep        過去の全記録から検索！ |
|                                                             |
|  ※さらに詳しい用語解説は各ボタンの「？」を見てね！          |
+-------------------------------------------------------------+
```
