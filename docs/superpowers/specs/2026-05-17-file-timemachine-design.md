# ファイルタイムマシン デザインドキュメント

## 1. プロジェクト概要
- **製品名**: ファイルタイムマシン (File Time Machine)
- **コンセプト**: 「Gitを意識させないGitクライアント」。
- **ターゲット**: Windows/Macを使用する、非エンジニアのクリエイターや事務職。
- **目標**: 専門用語を排除し、直感的な操作でファイルのバックアップ、分岐、復元を可能にする。

## 2. アーキテクチャ & 技術スタック
- **Framework**: Tauri (v2)
- **Frontend**: React + TypeScript
- **Backend**: Rust (Git/GitHub CLI のラップ、ファイル操作、環境診断)
- **Styling**: Vanilla CSS (オシャレかつ清潔感のあるデザイン)
- **Graphing**: SVG (Rust側で解析した履歴をReactで描画)
- **i18n**: 多言語対応。外部設定ファイル（JSON等）により後から言語追加が可能な設計。

## 3. UI/UX 仕様
### 3.1 メイン画面構成 (4カラム・可変幅)
1. **ファイルツリーペイン**: 
   - フォルダ構造を表示。`gitignore` 対象はグレーアウト。
2. **ルート管理ペイン**: 
   - 現在のルート（ブランチ）一覧。リスト/グラフ(SVG)切り替え。
3. **履歴リストペイン**: 
   - 履歴（コミット）をタイムスタンプ順に表示。
4. **プレビューペイン**: 
   - テキスト、画像、ファイル情報の閲覧（編集機能なし）。

### 3.2 共通仕様
- **可変幅 (Resizable)**: 各ペインの幅をドラッグで調整可能。
- **スクロールバー**: 全てのペインでコンテンツ溢れ時のスクロールバーを完備。
- **用語の変換**: 保存（Commit）、お試しルート（Branch）、本番に採用（Merge）、切り替える（Checkout）。
- **トーン**: システムメッセージおよびUIテキストはフォーマルなトーンで統一。

## 4. 主要機能
### 4.1 セットアップウィザード
- Git, Homebrew, GitHub CLI の有無を自動診断し、不足分をガイド。

### 4.2 保存 & 復元
- ワンクリック保存。ルート切り替え時の「確認後保存」または「自動保存」を設定可能。

### 4.3 安全ガード (Security & Safety)
- **除外・警告対象**: `.env`, `.pem`, `node_modules`, `venv`, `.DS_Store`, `Thumbs.db`, `.exe`, `.dll`, `.app`, `.dmg` 等。
- **制限**: 巨大ファイル(>100MB)、巨大リポジトリ(>1GB)、空フォルダ警告。
- **Gemini推奨ガード**: 作業開始前の「ファイル作成」推奨、重いリポジトリへの事前確認。

### 4.4 多言語化 (Internationalization)
- 日本語・英語を標準搭載。
- 言語リソースを分離し、ユーザーが新しい言語ファイルを追加できる拡張性を確保。

## 5. OS対応 & セキュリティ
- Win/Mac両対応。パスの安全性、認証情報のセキュア保存、脆弱性スキャンの実施。
