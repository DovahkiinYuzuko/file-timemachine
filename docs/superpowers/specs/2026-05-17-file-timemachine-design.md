# ファイルタイムマシン デザインドキュメント (v2)

## 1. プロジェクト概要
- **製品名**: ファイルタイムマシン (File Time Machine)
- **コンセプト**: 「Gitを意識させないGitクライアント」。
- **ターゲット**: Windows/Macを使用する、非エンジニアのクリエイターや事務職。
- **目標**: 専門用語を排除し、直感的な操作でバックアップ、分岐、復元を可能にする。

## 2. アーキテクチャ & 技術スタック
- **Framework**: Tauri (v2)
- **Frontend**: React + TypeScript
- **Backend**: Rust (Git/GitHub CLI のラップ、ファイル操作、環境診断)
- **Icons**: Lucide-react (SVGベース)
- **i18n**: 全世界主要言語対応 (外部JSON管理、RTL対応)
- **Auth**: GitHub OAuth (既定のブラウザで認証)

## 3. UI/UX 仕様
### 3.1 メイン画面構成 (サイドバー + 3カラム・可変幅)
1. **アクティビティ・バー (左端)**: 
   - アイコン（Lucide）による機能切り替え、設定・ヘルプへの入口。
2. **ファイルツリーパネル**: 
   - フォルダ構造を表示。`gitignore` 対象はグレーアウト。
3. **履歴・ルート管理パネル (上下2段)**: 
   - 上段: SVGグラフによるブランチ視覚化。
   - 下段: タイムスタンプ順の履歴リスト。
4. **プレビューパネル**: 
   - テキスト、画像の閲覧に特化。

### 3.2 共通仕様
- **可変幅 (Resizable)**: 各パネルおよび上下の境界をドラッグで調整可能。
- **用語の変換**: 保存（Commit）、お試しルート（Branch）、本番に採用（Merge）、切り替える（Checkout）。
- **トーン**: システムメッセージおよびUIテキストはフォーマルなトーンで統一。

## 4. 主要機能
### 4.1 究極の多言語対応 (i18n)
- **対応言語**: 日本語、英語、中国語（簡、繁）、韓国語、タイ語、ベトナム語、インドネシア語、スペイン語、フランス語、ドイツ語、ポルトガル語、イタリア語、ロシア語、アラビア語、ヒンディー語。
- **拡張性**: ユーザーが独自の言語ファイル（JSON）を追加可能な設計。

### 4.2 拡張設定 & GitHub 連携
- **GitHub OAuth**: 既定ブラウザを呼び出して安全に連携。
- **動作設定**: 自動保存の挙動や、脆弱性スキャンのON/OFFを設定可能。

### 4.3 ダブル・ヘルプ・システム
- **ツールチップ**: 各ボタンの横の「？」アイコンから用語解説を表示。
- **Gitコマンド早見表**: 操作と実際のGitコマンドの対応を学べる専用画面。

### 4.4 安全ガード (Security & Safety)
- 危険ファイル（.env, .exe等）や巨大ファイル(>100MB)の検知と警告。
- ルート切り替え時の自動作業中バックアップ（設定可能）。

## 5. OS対応
- Windows 11 / macOS 両対応。パスの正規化、既定ブラウザ連携、セキュアストレージ使用。
