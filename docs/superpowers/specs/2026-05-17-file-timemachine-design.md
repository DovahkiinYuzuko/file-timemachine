# ファイルタイムマシン デザインドキュメント (v3)

## 1. プロジェクト概要
- **製品名**: ファイルタイムマシン (File Time Machine)
- **コンセプト**: 「Gitを意識させないGitクライアント」。
- **ターゲット**: Windows/Macを使用する、非エンジニアのクリエイターや事務職。
- **目標**: 専門用語を排除し、直感的な操作でバックアップ、分岐、復元を可能にする。

## 2. アーキテクチャ & 技術スタック
- **Framework**: Tauri (v2)
- **Frontend**: React + TypeScript
- **Backend**: Rust (Git/GitHub CLI のラップ、ファイル操作、環境診断)
- **Icons**: Lucide-react (SVGベースに完全統一。絵文字の使用を禁止)
- **i18n**: 全世界主要言語対応 (外部JSON管理、RTL対応)
- **Auth**: GitHub OAuth (既定のブラウザで認証)
- **Dialogs**: tauri-plugin-dialog (フォルダ選択用)

## 3. UI/UX 仕様
### 3.1 メイン画面構成 (サイドバー + 3カラム・可変幅)
1. **アクティビティ・バー (左端)**: 
   - Lucideアイコンによる機能切り替え、フォルダ選択、設定、ヘルプ。
2. **ファイルツリーパネル**: 
   - 選んだフォルダの構造を表示。`gitignore` 対象はグレーアウト。
3. **履歴・ルート管理パネル (上下2段)**: 
   - 上段: SVGグラフによるブランチ視覚化。
   - 下段: タイムスタンプ順の履歴リスト。
4. **プレビューパネル**: 
   - テキスト、画像の閲覧に特化。

### 3.2 視認性 & スタイル
- **不透明モーダル**: 設定やヘルプ画面の背景は不透明な濃色（`#1e1e1e`等）とし、背後を `backdrop-filter: blur(8px)` でぼかす。
- **可変幅 (Resizable)**: 各パネル境界をドラッグで調整可能。
- **トーン**: システムメッセージおよびUIテキストはフォーマルなトーンで統一。

## 4. 主要機能
### 4.1 フォルダ選択 ＆ 既存Git対応
- **フォルダ選択**: サイドバーの `FolderOpen` アイコンから、OS標準のダイアログで管理対象フォルダを選択。
- **既存Git対応**: `.git` が既にある場合、既存の履歴を自動的に読み込む。`.gitignore` がない場合のみ、ホワイトリスト方式での作成を提案。

### 4.2 究極の多言語対応 (i18n)
- **16言語対応**: 日本語、英語、中国語（簡、繁）、韓国語、欧州・東南アジア主要言語、アラビア語(RTL対応)。

### 4.3 安全ガード (Security & Safety)
- 危険ファイルや巨大ファイルの検知・警告。
- Windowsパスの正規化（`dunce` 等を使用し、日本語パスや区切り文字のバグを防止）。

### 4.4 ログ & デバッグ
- `tauri-plugin-log` による統一ログ基盤。

## 5. OS対応
- Windows 11 / macOS 両対応。パスの正規化、既定ブラウザ連携、セキュアストレージ使用。
